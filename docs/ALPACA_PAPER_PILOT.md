# Alpaca PAPER pilot

Not a validated live release. Existing TSX scans and frozen forward books are unchanged. Use a dedicated paper account without manual trading. Set paper key/secret Actions secrets and the verified ALPACA_EXPECTED_PAPER_ACCOUNT_ID variable. Run check, then scan; both are read-only. Inspect registry quarantines and data coverage before setting ALPACA_PAPER_ENABLED=true to permit scheduled/manual tick paper orders. Default strategy is compression_family; balanced_blend is selectable. Default data feed is iex; entitled sip is selectable.

S&P membership is imported at runtime, not preverified in this commit. Unknown symbols/names are quarantined; AMD/AMZN excluded; SPY/QQQ retained. Signals use completed sessions and immutable definitions, but expanded universe/raw-feed/quote entries differ from prior backtests. The USD 1,000 risk reference is capped, not a separately funded or compounding subaccount. Whole shares, 25% allocation and 1.5% modeled-risk caps do not guarantee loss limits. Target R uses the entry limit, not the eventual fill.

GitHub scheduling, cancellation, partial-fill flattening and seventh-session exits are best-effort, not continuous or guaranteed. Delays can leave GTC entries live past the opening window. Failures can leave virtual exposure; review the paper dashboard. Disabling the flag stops coordinator mutations, not existing broker orders. Broker fills and artifacts are the record; submission is not completion/profit. Actual credentials, market-data entitlement, public-source availability and end-to-end execution are unvalidated. IEX is exchange-only data. No live endpoint or override exists.
